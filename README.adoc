This repo works as the "heavyweight" benchmark app for a DevOps and CI/CD deployment study

The study compares DORA-style metrics across AWS and Azure container platforms

The app is intentionally heavy, big stack, Lots of moving parts

It combines Next.js, Express.js, and Sequelize into one tightly coupled fullstack setup. It also supports SSR, SSG, and ISR. Build complexity goes up fast

This repo acts like a heavyweight benchmark. Good for testing deployment behavior under equal containerized conditions

Stuff like trigger latency, build execution time, lead time for changes, deployment frequency, change failure rate, and MTTR
